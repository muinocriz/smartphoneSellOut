# 公开图卡文案规范（模块 3 工作台）

> 适用范围：工作台生成的四类基础图卡，以及热销机型追踪的 14 个研究专题。主要面向数码爱好者和普通网友。此规范限定**默认公开图卡及随附公众文案**，不改变分析模型、研究界面的质检提示、CSV 和可追溯的研究参数。

## 一、各展示位置的职责

| 位置 | 默认用途 | 不应放置的内容 |
| --- | --- | --- |
| 主标题 | 一眼知道要回答什么市场问题 | 内部模块名、不能证明的市场结论 |
| 副标题 | 补充比较对象或指标 | 拟合、标定、容差、算法实现、原始分母 |
| 榜单标签 | 周次/区间，必要时标注 TOP30 | 标定数量、有效周统计、CSV 文件名、原始全量 |
| 图表内附注 | **只保留会改变读图结论的一句话**，通常 0—1 行 | 版本号、工程参数、自动检查次数、缺失数据的实现细节 |
| 底部说明 | 来源、估算性质、样本覆盖边界，原则上两行 | 校准点、拟合系数、内部模块代号、导出/调试过程 |

例如：“标定2组”对公众意义有限；应保留在内部质量检查。“保留原始分母”不直观；如果关系到比较，改成“上下图统计范围不同”。“色带只连接同品牌”可表述为“色带只表示同品牌变化”，避免误读成消费者转移。

## 二、四类基础图卡的默认文案

| 模板 | 主标题 | 副标题 | 榜单标签 | 图表内附注 |
| --- | --- | --- | --- | --- |
| TOP10 排行榜 | 热销机型 TOP10 | 本榜单前十名 · 销量估算 | 榜单周次和规模 | 无 |
| 双机销量 PK | 同榜机型 销量 PK | 同一榜单 · 销量差距 | 榜单周次和规模 | 无 |
| 品牌上榜实力 | 品牌上榜实力 | 各品牌入榜销量与占比 | 榜单周次和规模 | 品牌合并规则保留一行 |
| 榜首领先分析 | 榜首究竟有多强？ | 榜首差距与样本销量占比 | 榜单周次和规模 | 无 |

基础图卡底部默认文案为两行（实际绘制按可用宽度自动换行）：

> 来源：{榜单来源} · 榜单销量为估算值  
> 仅统计本次入榜机型，不代表全市场销量或份额

四类基础图卡的销量数字不重复写“万台”；渲染页脚在当前声明没有“万台”时统一补充“销量单位：万台”。这属于展示层，不改变估算值、CSV或用户编辑的文案状态。研究图轴标题、百分号及pp等必要单位继续保留。

品牌卡额外说明品牌集团合并范围：“品牌合并：小米/REDMI · OPPO/一加/realme · vivo/iQOO”。这是理解品牌分组所需的信息，不属于后台标定术语。

历史榜单标签保留真实周次、TOP 规模；若 TOP30 不完整，仍显示实际记录条数，避免误称完整榜单。新上传截图的文件名若没有可识别的周次，则默认用“本期入榜样本”，不直接把 IMG_**** 等文件名放到公众图卡。

## 三、14 个专题的公众默认标题与附注

| 专题 | 公众主标题 | 公众副标题 | 图表内附注（必要时） |
| --- | --- | --- | --- |
| 机型销量趋势 | 机型销量趋势 | 重点机型销量走势 | 只有存在缺失周估算时，提示“空心点代表补充估算，不能当作实测销量” |
| 代际替代分析 | 新旧机型销量对比 | 两代合计周销量与新代替代率 | 替代率为新代周销量占比，不代表实际换机；含插补时说明浅色柱及折线虚线段 |
| 产品结构分析 | 产品结构分析 | 不同产品类型的销量表现 | 无 |
| 同档代际对比 | 同档代际对比 | 同价位新旧机型销量比较 | 只对比所选机型，不代表同价位全部产品 |
| 长尾韧性分析 | 长尾韧性分析 | 上市年龄与近期销售活跃度（散点） | 周均销量只计近期实际入榜周；未上榜不代表停销或零销量 |
| 榜单流动分析 | 榜单流动分析 | 哪些机型进入或退出榜单？ | 进入或退出榜单，不等于上市或停销 |
| 榜单品牌结构与集中度 | 榜单品牌结构与集中度 | 各品牌上榜表现与集中度 | 只有堆叠连接图出现时，说明浅色带并非销量迁移 |
| 榜内与全市场品牌竞争分析 | 榜内与全市场品牌竞争分析 | 品牌份额与增长来源 | 流向视图：上下图统计范围不同；色带仅连接同一品牌；增长视图：榜外、总销量变化为模型情景，区间跨零时方向不确定 |
| TOP30市场覆盖率与销量分层 | TOP30市场覆盖率与销量分层 | 市场规模及销量分层 | SKU开启：紫线为市场总销量情景中点；下图榜外为推导值；关闭：紫线仅为市场下界，不绘制分层 |
| 价格带竞争分析 | 价格带竞争分析 | 不同首发价位的销量表现 | 价格按首发起售价划分，并非实际成交价 |
| 品牌产品定位分析 | 品牌产品定位分析 | 各品牌首发价位与销量分布 | 价格为首发价，不代表实际成交均价 |
| 芯片平台竞争分析 | 芯片平台竞争分析 | 不同芯片平台的上榜表现 | 无 |
| 新老代际结构分析 | 新老代际结构分析 | 新旧代际销量占比 | 代际年龄按同代最早正式开售日计算，后发型号不重置 |
| 多维产品竞争分析 | 多维产品竞争分析 | 不同产品属性的销量分布 | 仅比较所选产品属性及入榜机型 |

“机型销量趋势”若切换到原始排名模式，则标题、副标题改为“机型榜单排名走势 / 重点机型在榜单中的排名变化”；销量＋排名模式使用“机型销量与榜单排名 / 销量与排名一起看”。“TOP30市场覆盖率与销量分层”根据销量区间、覆盖率区间、环比指数和偏差视图自动更换副标题，不能把环比偏差图称为销量图。双周品牌对比使用“双周品牌市场份额变化贡献 / 榜内与榜外贡献及全市场份额变化（pp）”，明确榜内和榜外贡献为条件性估算、统一全市场分母，范围非统计置信区间；多周堆叠不变。

## 四、研究专题榜单标签及底部说明

研究专题标签默认只用当前图表实际展示的周次或区间；扩展销量模式追加「· 扩展样本」，不把扩展样本标为完整TOP30；跨周双图显示两个被比较的周次。TOP30 对照图和覆盖率研究追加“· TOP30”，帮助读者定位样本范围。上市后销售周采用“上市后周次”的自然语言，不直接写统计方法名称。

研究专题底部默认模板：

| 研究类型 | 第一行 | 第二行 |
| --- | --- | --- |
| 普通榜单研究 | 来源：{来源}/{系列} · 榜单销量为估算值 | 仅统计入榜样本，不代表全市场销量或份额 |
| 扩展销量研究 | 来源：重点机型周增量／累计差分 + {来源}/{系列} TOP30估算 | 扩展样本按覆盖范围去重，不代表全市场销量或份额 |
| 原始排名研究 | 来源：{来源}/{系列} · 榜单销量为估算值 | 排名只代表所选榜单，不是全市场排名 |
| 榜单与全市场品牌对照 | 来源：{来源}/{系列}；对照：全市场品牌份额数据 | TOP30仅代表入榜样本（或：榜单样本占比不等于整体市场份额） |
| TOP30 市场规模估算 | 来源：{来源}/{系列}；对照：全市场品牌份额数据 | 市场总销量为条件性估算，不是官方统计 |

底部说明不重复图表中的所有条件。若存在会影响解释的例外（例如品牌分组、缺失周补充估算、非成交价），放在**一条简短的图表内附注**而非叠加一整段免责声明。

## 五、内部信息如何保存

下列信息**不在公众图卡默认显示**，但继续保留在研究数据、详细配置、工作台状态或导出文件中：拟合系数及标定组数、排除异常值说明、原始分母、数据完整周计数、插补参数、SKU 假设、苹果入榜率推导、量化环比容差、连续异常状态、版本指纹、原始 CSV 名、数据源模块编号。

本规范仅清理默认输出，不覆盖用户已手动编辑的标题、副标题、标签或注释。图表数值、榜单排序、品牌分组、统计口径及数据有效性检查不受影响。

## 六、发布前人工核对

1. 标题、副标题准确反映当前选中的图表视图（销量、排名、份额或价格）。
2. 标签呈现真实周次；如有不完整榜单，不误称完整 TOP30。
3. 含市场规模估算的图卡，不把估算区间叫做“真实误差”或“官方销量”。
4. 底部样本声明与图表范围一致；不会把 TOP30 样本份额写成全市场份额。
5. 正文、轮播脚本的默认稿只保留公众说明；需要详细方法时使用工作台统计口径文件。

## 七、扩展销量样本的公众文案（2026-11-25）

原始榜单和扩展销量必须区分；工作台依据冻结快照 config.sampleMode 生成默认文案，不依当前实时选择重算。扩展模式适用于10个销量专题，原始排名/矩阵、长尾、流动、跨市场研究仍按原口径。双图销量使用扩展样本时，排名仍来自原始榜单。

| 专题 | 扩展模式关键读图提示 |
| --- | --- |
| 机型销量 | 缺失不等于零；合计项不拆分；双图注明原始排名 |
| 代际替代 | 替代率为新代占两代合计比例，不代表实际换机 |
| 产品结构、同档对比 | 仅统计所选样本或范围，不代表市场份额；缺失不等于零 |
| 价格带、品牌定位 | 正式首发价而非成交价；无法归类的合计项保留未知；加权首发价不是ASP |
| 芯片、年龄、多维竞争 | 共同属性才归类；跨类别、未知年龄不强行拆分 |
| 品牌结构 | 主标题「品牌销量结构与集中度」，副标题「扩展样本中的品牌销量表现」；占比使用扩展样本分母，色带非销量迁移 |

芯片专题副标题改为「不同芯片平台的样本销量表现」。扩展统计项计数不是SKU数量，也不是上榜数量。不得统一称所有扩展销量为榜单估算；应保留跟踪周增量、累计差分和榜单估算的来源区别。完整技术参数和筛选前来源汇总保留在统计CSV与冻结配置，机型CSV保留逐条来源与覆盖成员。显示文案可以手动编辑，不改变统计事实。当前仅完成代码及文档接入，未执行发布验收。

## 八、移动端公开图卡的文字层级（2026-11-25 UTC）

工作台图卡优先3:4竖屏，9:16为补充。常规坐标轴12/400（自然周及数字使用 IBM Plex Mono），图例10/400，来源、图内附注和底部统计声明8/400；堆叠内部数值及百分号10/400（窄色块局部8–10），普通销量数字12/500。字号仅为展示基准，不代表统计指标改变。

- 同年自然周的图内坐标标签用 WXX，跨年保留年份；标题下方统计区间仍保留完整年份，非自然周类别不改写。
- 图例不拆分英文单词，长项目优先独立占行；X轴下方图例保留至少8逻辑单位净距。图内附注保持精简但必须保留影响结论的必要说明。
- 柱内标签因极小色块空间不足而隐藏时，不表示该类别为零或数据缺失；以完整统计表、图表CSV和统计口径为准。普通双周流向的小色块仍采用引导标注。公开图卡前由维护者核对数据标签、来源声明及实际手机阅读效果。
- 当前固定整数周步长方案尚未实现；其他密集图表可能存在局部字号适配。详细参数与实现边界见 [维护与设计指南](MAINTAINER_GUIDE.md) 和 [模块3架构](MODULE3_ARCHITECTURE.md)。
