## 派生 CSV
原始榜单事实数据为 sales-estimates.csv，扩展样本另使用 sales-long.csv 及 model-master.csv；页面实时计算，不依赖离线派生文件。现有构建生成物仍是原始榜单口径的 weekly-sales-panel，不是扩展样本。默认口径覆盖率 80%、首次观测分母、最长 3 周、门槛约束插补。每次 Cloudflare 构建自动生成 dist/studio/weekly-sales-panel.csv 和 weekly-sales-panel.meta.json，不写回 GitHub。清单包含源文件、算法和品牌规则 SHA-256、输出哈希、版本、参数和行数。算法逻辑变更应更新 SalesSeries.VERSION。导出 CSV 附带算法版本。
旧 weekly-sales-panel.csv 已从当前分支移除，可通过 Git 历史找回。运行 npm run generate:panel 在 generated/ 生成本地副本和清单（不纳入版本控制）；也可传入目标目录（npm run generate:panel -- <目录>）。构建不覆盖原始 CSV。生成清单不含时间戳，便于相同输入的可复现性比较。

本项目不再维护 tests/ 自动测试目录；人工验收需检查模块2/3访问、研究导航及恢复、图表预览/导出、重新加载配置和部署生成物。

## 机型主数据与统一序列身份

- 根目录 `model-master.csv` 是长期属性表，独立于 `sales-estimates.csv`，首次入库 53 行、19 列；V3.3 初始接入 110 行、20 列，UTF-8 BOM。生产构建复制同一源文件至 `/studio/model-master.csv`（Access 保护路径）和公开 `/model-master.csv`（模块4读取），文件内容不再视为秘密。
- 字段顺序：`model_id,model_name,brand,brand_group,aliases,series,generation,variant,form_factor,sale_start_date,predecessor_id,launch_price,chip_vendor,chip_model,base_ram,base_rom,source_url,notes,verification,tracking_group`。末列用于累计跟踪统计组，不替代产品系列或代际。`model-master-v2` 解析器当前兼容19列原表头及20列新表头，导入19列时跟踪组为空。
- 关联规则：永久机型 ID 唯一，名称与别名用现有 BrandUtils.normalize 精确匹配；不自动合并不同型号。新上榜补录，退出保留，重新上榜复用。合并统计项独立保留，不分摊销量。上一代 ID 可以指向尚未入库或无销量的机型；不因此拒绝文件，不补零或计算无依据的代际增速。
- 正式开售日期优先（中国大陆），发布会、媒体沟通会、预约、开始预售不得直接视为开售。若无法查证正式开售日而正式发布日期已知，暂按发布即开售使用发布日期，并在 notes 或 verification 注明依据与暂定状态；后续查证后同步更正宽表、长表及主数据。两者均未知时留空待核实。无需增加日期字段；首发价为不含限时折扣、补贴、平台优惠及后续降价的正式定价（人民币元），起售 RAM/ROM 与该价对应（GB），数值无单位后缀。芯片名称以维护者归类为准，不自动剥除后缀。来源、备注与核查文本不覆盖结构化字段；缺失或不适用的属性按专题隔离处理并报告覆盖率。加权首发价不是 ASP。
- `model-master.js`（浏览器和 Node 共用）使用 SalesSeries.readCSV 通用解析器，提供 parse/load、get/resolve/getSeries/getPredecessor、enrich/audit；索引标准名称、分号分隔别名、永久 ID 及品牌+系列。ID 或跨机型名称冲突阻止主数据加载，不自动猜测；数值/日期缺失或格式错误单独保留为空，审计报告，不修改源文件。
- SalesSeries.sequenceIdentity 在构建周榜时统一使用永久 `model_id`，未关联的机型使用保留前缀 `unmatched:` 加规范化名称；原始榜单名称留在 raw_model。派生数据采用 sequence_id、model_id（未匹配留空），删除旧 model_key 字段，不做旧配置迁移。同一期榜单若多个原始名称指向同一身份，拒绝该研究序列，避免重算和重复累计；原始历史读取仍独立。尚未补录的新机型不丢弃。
- 机型主数据异步独立加载，等待首次读取结果后构建研究序列；失败时保留历史读取并以未匹配标识提供销量研究，不保存临时配置，允许重试。重试成功清除临时选择/分组，重新构建。研究配置 research v6、发布方案 publication v8，旧版本不迁移。
- 移除硬编码 iPhone 名称主键及预设；默认机型取最新有效榜单中的符合研究口径的前五（不足时补足），产品结构的属性分组按显式属性筛选及当前统计模式生成，代际预设依据明确 predecessor_id，允许前代未收录；保留手动分组。固定组统计仍严格处理缺失，不自动缩减成员。现已接入价格、芯片、产品定位、年龄结构及多属性交叉专题。
- `weekly-panel-v2` 在浏览器与构建侧共用身份逻辑；派生 CSV 和研究导出携带主数据版本指纹，生成清单 schema v2 增加主数据及关联代码 SHA-256。构建要求有效主数据，防止错误发布。模块3研究 JS 和原始榜单仅在 /studio/ 白名单下提供；共享销量长表和机型主数据根路径公开，并保留授权路径副本。未执行构建、测试或线上验收。
