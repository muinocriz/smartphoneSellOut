# 长期决策与业务口径

| 范围 | 约定及理由 |
| --- | --- |
| 跨市场研究周历 | 榜单与全市场 CSV 独立更新；跨市场研究使用所选榜单来源的周历与全市场周历并集的自然周范围（保留中间缺周），各自份额独立展示，仅同周具备所需输入时计算覆盖率及贡献；不得用市场份额推造原始榜单。其他专题不扩展至市场份额周历。 |
| 样本与缺失 | 跟踪销量数据采用精选机型样本，退出样本表示停止采集；榜单研究按各期覆盖范围解释。缺失、销量为零、未上榜含义不同，保留原始排名和缺失状态。 |
| 时间轴 | 自然周用 ISO 周。以开售后的首个完整周对齐生命周期，首个不足周单独标记；共用 iso-sales-week.js 处理周一与跨年边界。 |
| 特殊数值 | 旧版销量追踪模块曾将宽表正累计值恰为 50 万台整数倍视作里程碑下限；销量数据处理模块宽表同步不推断该旧语义，有效无符号数值按精确值处理。销量数据处理模块、销量增量追踪模块长表显式区分运算符；同步、绘图和差分应保留精确值、约值与上下界的语义。微博导入默认将常规「约」作为统计点值（=），可切换为 ≈ 并记忆选择；近、左右、上下保留估计语义，严格大于在现有运算符范围内按 ≥ 保存并提示。无效标题中断上下文，未知开售日期留空，荣耀保留完整分类，历史元数据不自动覆盖。 |
| 周销量优先级 | 销量增量追踪模块的 seriesRows 优先取相邻精确累计差，再取直接周记录。热销机型与榜单研究模块扩展融合先取精确周记录，再取可靠累计差分，再用完整原始 TOP30 估算补充；按覆盖去重，合计项不拆分。两条路径服务不同分析。 |
| 机型身份 | 永久 model_id 连接名称和别名。无法精确关联时保留独立身份和原名，重新上榜可复用；未知属性仍计入相应覆盖率分母。 |
| 份额与规模 | 品牌集团份额已含所列子品牌，避免重复相加。华为自 2026W47 起含 OSTA 星芒；`market-share.csv` 的 `OSTA` 列为子品牌份额，发布前已知零销量记 0，之后未披露记空，主品牌拆分同样缺失。母品牌键仍为 `华为`，展示为「华为系」，机型独立品牌使用 `OSTA`（显示 OSTA 星芒），主品牌仍为华为；不把星芒另计为第七集团。比较份额时保留原分母；展示周间规模时保留总量差；堆叠间色带表示同品牌连续性。 |
| 数据写入边界 | 页面草稿用于当前操作，正式 CSV 由维护者导出后提交；可视化插补和下载展示精度不改变原始销量。 |
| 图表出口 | 页面、桌面 PNG、手机 PNG 有不同绘制路径。修正坐标轴、标记、精度或文案时先界定影响哪些出口，再沿 [索引](CODE_MAP.md) 查共享函数及各自调用点。 |

机型字段、选题和绘图规格详见 [维护指南](../MAINTAINER_GUIDE.md)。仅在约定或其适用范围改变时更新本表。
